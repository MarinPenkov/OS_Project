# Проект: Course Enrollment System

## Описание

Проектът „Course Enrollment System“ представлява уеб приложение, разработено с PHP и MySQL, което позволява управление на записвания за курсове.

Системата предоставя възможност за:

* преглед на наличните курсове;
* записване на студенти в избран курс;
* предотвратяване на дублирани записвания;
* преглед на всички записвания чрез административен панел;
* изтриване на съществуващи записвания.

Проектът е контейнеризиран чрез Docker и Docker Compose, като отделните компоненти са разделени в самостоятелни контейнери.

# Изграждане и стартиране на контейнерите

Проектът използва Docker Compose за автоматично изграждане и стартиране на всички необходими услуги.

Изграждане и стартиране:

```bash
docker compose up --build
```

Спиране на контейнерите:

```bash
docker compose down
```

Премахване на контейнерите и обемите:

```bash
docker compose down -v
```

След успешно стартиране приложението е достъпно на адрес:

```text
http://localhost:8080
```

# Компоненти на системата

## Web Container

Уеб контейнерът е изграден върху образа `php:8.2-apache`.

Той съдържа:

* PHP приложението;
* HTML интерфейса;
* CSS стиловете;
* JavaScript функционалността;
* Apache уеб сървър.

Основните му задачи са:

* визуализиране на курсовете;
* обработка на формата за записване;
* показване на административния панел;
* комуникация с базата данни.

---

## Database Container

Контейнерът за базата данни е изграден върху образа `mysql:8.0`.

Той съдържа:

* база данни `course_system`;
* таблица `courses`;
* таблица `students`;
* таблица `enrollments`;
* начални данни за наличните курсове.

При първото стартиране SQL скриптът автоматично създава таблиците и зарежда началните записи.

# Комуникация между услугите

Комуникацията между контейнерите се осъществява чрез Docker Compose мрежа.

В системата са дефинирани две услуги:

* `web`
* `db`

PHP приложението осъществява връзка към MySQL чрез името на услугата:

```php
$host = "db";
```

Docker Compose автоматично създава вътрешна мрежа, чрез която web контейнерът може да комуникира директно с database контейнера.

Това позволява цялата система да функционира като едно приложение, въпреки че е разделена на отделни контейнери.

# Контейнеризация на проекта

Проектът е контейнеризиран чрез Docker, като приложението е разделено на две независими услуги:

1. Web Service – PHP 8.2 и Apache.
2. Database Service – MySQL 8.0.

Всеки компонент има собствен Dockerfile, а Docker Compose управлява тяхното изграждане, стартиране и комуникация.

По този начин проектът може да бъде стартиран на всяка система с инсталиран Docker чрез една единствена команда:

```bash
docker compose up --build
```
